## 1. Εισαγωγή / Introduction

**Vetty** είναι το σύστημα διαχείρισης της κτηνιατρικής σας κλινικής. Επιτρέπει:
- Διαχείριση ραντεβού με ημερολόγιο
- Αρχείο πελατών και κατοικιδίων
- Ψηφιακές συνταγές
- Διαχείριση αποθήκης & φαρμάκων με ημερομηνίες λήξης
- Αναζήτηση στο εθνικό μητρώο (pet.gov.gr) μέσω μικροτσίπ
- Αυτόματες ειδοποιήσεις email & SMS για ραντεβού και εμβόλια

**Vetty** is the management system for your veterinary clinic. It handles appointments, customer & pet records, prescriptions, stock management, and automated reminders.

## 2. Σύνδεση & Αποσύνδεση / Login & Logout

### Σύνδεση / Login

📸 `[SCREENSHOT: Οθόνη σύνδεσης — login form με πεδία Όνομα και PIN]`

**Βήματα / Steps:**
1. Ανοίξτε τον browser και πηγαίνετε στη διεύθυνση της εφαρμογής.  
   *Open the browser and navigate to the app URL.*
2. Γράψτε το **Όνομά σας** στο πρώτο πεδίο.  
   *Enter your **Name** in the first field.*
3. Γράψτε το **PIN** σας (αριθμητικός κωδικός).  
   *Enter your **PIN** (numeric code).*
4. Πατήστε **Σύνδεση / Login**.

> **Προσοχή / Note:** Αν κάνετε 10 λανθασμένες προσπάθειες σύνδεσης, το σύστημα κλειδώνει την IP σας για 15 λεπτά.  
> *After 10 failed attempts, your IP is blocked for 15 minutes.*

3. Γράψτε το **παλιό PIN** και το **νέο PIN** (ελάχιστο 4 ψηφία).
4. Πατήστε **Αποθήκευση**.

### 4.1 Δημιουργία Ραντεβού / Create Appointment

📸 `[SCREENSHOT: Κλικ σε κενό slot → ανοίγει η φόρμα νέου ραντεβού]`

**Βήματα / Steps:**
1. Επιλέξτε **ημερομηνία** από το ημερολόγιο (αριστερά).
2. Κάντε κλικ σε έναν **κενό χρονικό χώρο** (slot) για να επιλέξετε ώρα.
3. Η φόρμα ανοίγει αυτόματα. Συμπληρώστε:

| Πεδίο | Υποχρεωτικό | Περιγραφή |
|-------|------------|-----------|
| **Πελάτης / Ζώο** | ✅ | Αναζήτηση ή γρήγορη δημιουργία |
| **Τύπος ραντεβού** | ✅ | Π.χ. Εξέταση, Εμβολιασμός, Grooming |
| **Διάρκεια** | ✅ | Σε λεπτά (default: 30) |
| **Γιατρός** | — | Default: "Ιατρείο" |
| **Σημειώσεις** | — | Εσωτερικές σημειώσεις |

4. Πατήστε **Αποθήκευση**.

> **Σύγκρουση ραντεβού / Overlap detection:** Αν η επιλεγμένη ώρα συγκρούεται με υπάρχον ραντεβού του ίδιου γιατρού, το σύστημα εμφανίζει σφάλμα και δεν αποθηκεύει.  
> *If the time conflicts with an existing appointment for the same doctor, the system shows an error and blocks saving.*

### 6.5 Αναζήτηση στο Μητρώο (pet.gov.gr) / Registry Lookup

📸 `[SCREENSHOT: Tab μητρώου — πεδίο αναζήτησης μικροτσίπ]`

Το σύστημα μπορεί να αναζητήσει ζώο **απευθείας στο Εθνικό Μητρώο** (pet.gov.gr) μέσω μικροτσίπ.

**Βήματα / Steps:**
1. Ανοίξτε το προφίλ κατοικιδίου → Tab **Μητρώο**.
2. Εισάγετε τον **αριθμό μικροτσίπ** (10-20 ψηφία).
3. Πατήστε **Αναζήτηση**.
4. Τα αποτελέσματα εμφανίζονται αυτόματα.
5. Πατήστε **Αποθήκευση Snapshot** για να αποθηκεύσετε τα δεδομένα στο αρχείο του ζώου.

> **Προϋπόθεση:** Ο Registry Worker πρέπει να είναι ενεργός. Ο admin μπορεί να τον ενεργοποιήσει από **Ρυθμίσεις → Registry Worker → Εκκίνηση**.

### 8.2 Διαχείριση Παρτίδων (Batches) / Batch Management

📸 `[SCREENSHOT: Section παρτίδων με πίνακα batch numbers]`

Κάθε προϊόν μπορεί να έχει **πολλαπλές παρτίδες** (lotteries/batches) — χρήσιμο για φάρμακα με διαφορετικές ημ. λήξης.

**Προσθήκη παρτίδας / Add batch:**
1. Ανοίξτε το προϊόν.
2. Πηγαίνετε στο section **Παρτίδες**.
3. Πατήστε **+ Νέα Παρτίδα**.
4. Συμπληρώστε:

| Πεδίο | Περιγραφή |

## 12. Συχνές Ερωτήσεις / FAQ

### Ξέχασα το PIN μου. / I forgot my PIN.

Επικοινωνήστε με τον **administrator** της κλινικής. Ο admin μπορεί να επαναφέρει το PIN σας μέσω του script:
```bash
# Ο admin τρέχει στον server:
node scripts/addUser.js  # ή μέσω MongoDB Compass
```

---

### Γιατί δεν μπορώ να αποθηκεύσω ραντεβού; / Why can't I save an appointment?

Πιθανές αιτίες:
1. **Σύγκρουση ώρας** — Υπάρχει ήδη ραντεβού για τον ίδιο γιατρό την ίδια ώρα. Επιλέξτε άλλη ώρα.
2. **Λείπουν υποχρεωτικά πεδία** — Ελέγξτε ότι έχετε συμπληρώσει Πελάτη, Ζώο, Τύπο ραντεβού.
3. **Δεν έχετε άδεια** — Ο ρόλος σας δεν επιτρέπει εγγραφή ραντεβού (επικοινωνήστε με admin).

---

### Δεν εμφανίζονται διαθέσιμα slots. / No available slots showing.

Ελέγξτε ότι:
1. Το ωράριο της κλινικής έχει οριστεί στις **Ρυθμίσεις → Ωράριο**.
2. Η επιλεγμένη ημέρα είναι **ενεργή** (enabled).
3. Έχετε επιλέξει τη σωστή ημερομηνία.

---

### Η αναζήτηση μικροτσίπ δεν λειτουργεί. / Microchip search not working.

Ελέγξτε:
1. **Ρυθμίσεις → Registry Worker** — ο worker να είναι **Ενεργός** (🟢).
2. Αν είναι σταματημένος, πατήστε **Εκκίνηση** (χρειάζεστε δικαιώματα admin).
3. Ο αριθμός μικροτσίπ να είναι **10-20 ψηφία**, μόνο αριθμοί.

---

### Γιατί δεν στέλνονται email ειδοποιήσεις; / Why aren't email notifications being sent?

Ελέγξτε:
1. **Ρυθμίσεις → Email Configuration** — να έχουν οριστεί τα SMTP στοιχεία.
2. Ο πελάτης να έχει **email** καταχωρημένο.
3. Στο προφίλ πελάτη, οι **Email ειδοποιήσεις** να είναι ενεργές.

---

### Πώς ενημερώνονται τα δεδομένα σε πραγματικό χρόνο; / How does real-time sync work?

Το σύστημα χρησιμοποιεί **WebSockets** (Socket.io). Όταν ένας χρήστης κάνει αλλαγή, όλοι οι άλλοι χρήστες βλέπουν την αλλαγή αμέσως, χωρίς ανανέωση σελίδας.  
*When one user makes a change, all other connected users see it instantly without page refresh.*

---

### Πώς λειτουργεί το dark mode; / How does dark mode work?

**Ρυθμίσεις → Γενικές Ρυθμίσεις → Σκοτεινό Θέμα** — toggle on/off. Η ρύθμιση αποθηκεύεται στη βάση δεδομένων και εφαρμόζεται σε όλες τις συσκευές.
