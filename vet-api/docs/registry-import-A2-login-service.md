# A2 — Βασικό service για LOGIN στο registry (χωρίς ακόμη scraping)

Στόχος A2:

- Να βάλουμε στο `.env` μεταβλητές για το external registry.
- Να φτιάξουμε ένα service `registryScraper.js` που:
  - διαβάζει τις REGISTRY_* μεταβλητές
  - ανοίγει browser με Playwright
  - πηγαίνει στη σελίδα login του registry
- Να φτιάξουμε ένα μικρό test script που καλεί το service.

Σε αυτό το βήμα ΔΕΝ τραβάμε ακόμη δεδομένα κατοικιδίου.  
Μόνο ελέγχουμε ότι μπορούμε να κάνουμε login σε μια σελίδα.

> Σημαντικό:  
> ΜΗΝ στείλεις σε μένα τους πραγματικούς κωδικούς σου.  
> Τους κρατάς μόνο στο `.env` τοπικά στο pc σου.
